# SOMNA · 冥想睡眠

> 一款主打「助眠 + 冥想」的移动端网页应用，用温柔的夜色 UI 陪你从清醒滑入睡眠。

SOMNA 把睡眠计划、呼吸引导、环境音混音与睡眠报告收进一个极简的 App 外壳里，
纯静态实现，无需后端、无需构建，打开即用。

## ✨ 功能特性

- **今夜首页**：设置今晚的入睡 / 醒来计划，一键开启呼吸引导。
- **呼吸引导播放器**：全屏极光背景 + 呼吸光球，支持 4-7-8 呼吸节奏、播放 / 暂停、后退 / 前进 30 秒、循环、静音。
- **混音实验室**：叠加「雨声 / 海浪 / 森林 / 营火」四层环境音，独立音量调节，保存专属睡眠音景（含演示数据）。
- **睡眠报告**：睡眠评分环、睡眠阶段（深睡 / 浅睡 / REM / 清醒）柱状图、关键指标卡与个性化建议（演示数据）。
- **底部标签导航**：今夜 / 混音 / 报告 三页切换，移动端沉浸式外壳（状态栏 + Home Indicator）。

## 🛠 技术栈

- 纯 **HTML + CSS + 原生 JavaScript**，零依赖、零构建。
- 状态与设置通过 `localStorage` 持久化（键名前缀 `somna-`）。
- 图标为内联 SVG `<symbol>` 雪碧图，无需额外图标库。
- 响应式移动端布局，建议以移动视口（或浏览器移动模拟）体验。

## 🚀 本地运行

直接双击 `index.html` 即可在浏览器打开；为获得完整的 `localStorage` 与音频行为，
建议使用本地静态服务器：

```bash
# 任选其一
python -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080/`。

## ☁️ 部署

任意静态托管均可，例如 Cloudflare Pages / GitHub Pages / Gitee Pages：

- **构建命令**：无（纯静态）。
- **发布目录**：仓库根目录。
